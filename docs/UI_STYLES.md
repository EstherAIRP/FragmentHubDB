# Web 樣式規則

全站樣式集中在 `app/globals.css`，沿用淺色背景、深色主要操作與紫色分類標籤。

## 共用設計變數

- 色彩：使用 `--color-*` 語意變數；正文、次要文字、邊框、表面與狀態各有固定用途。
- 字級：使用 `--text-*`；輔助資訊最小 12px，正文 16px，頁面標題 28–36px。
- 間距：使用 `--space-*`，以 4px 為基準；面板內距 24px，主要區塊間距 16px。
- 圓角：控制項 8px、卡片內部 12px、大面板 20px；標籤使用 pill。
- 陰影：卡片、懸停、選取、選單、對話框使用各自的 `--shadow-*`。
- 控制項：主要按鈕、輸入欄位、選單選項最小高度 44px。

## 元件與互動

沿用既有 class：`primaryButton`、`secondaryButton`、`dangerButton`、`panel`、`fragmentCard`、`boardCard` 等。新增頁面應優先共用這些規則，避免另外建立相似的色彩與尺寸。

鍵盤焦點必須清楚可見；整張卡片的連結以父卡片顯示焦點。停用按鈕降低透明度，且不套用一般按鈕的懸停色彩。表單與標籤輸入框提供外框焦點提示。

760px 以下主要內容改為單欄；480px 以下導覽換行、標籤移除與篩選操作擴大觸控範圍。長文字允許換行，新增／編輯表單使用單欄，按下建立或儲存後顯示內容確認視窗；視窗內容可捲動，操作按鈕保持可見。遵守 `prefers-reduced-motion`，停用動畫、轉場及卡片位移。

## 驗證

調整樣式後檢查 320、375、768、1024、1440px 的排版、鍵盤焦點與減少動畫設定。私人頁面的實際驗收須使用既有登入流程；可先用不含私人資料的元件示範內容檢查 CSS。
